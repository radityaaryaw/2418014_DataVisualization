*DATA VISUALIZATION - DATASET LOG TRANSAKSI VENDING MACHINE*

Dataset log transaksi vending machine ini dipilih karena sistemnya bisa merekam aktivitas penjualan secara otomatis dan real-time tanpa interaksi manusia, sehingga data yang dihasilkan akurat. Namun di sisi lain, ternyata suatu mesin juga memiliki kekurangan maupun ketidaksetaraan isi variabel yang berantakan seperti format tanggal yg tidak sesuai, adanya data kosong, dll.
Oleh karena itu, pentingnya proses cleansing hingga visualisasi data dilakukan untuk bisa mengetahui kejanggalan yang ada dan memvisualisasikan data menjadi suatu informasi yang sangat berguna dan mudah dipahami guna mengevaluasi kinerja sistem bisnis secara lansung.

Tujuan Visualisasi Data :
1. Memvisualisasikan data menjadi grafik yang mudah dipahami.
2. Mengetahui tren pendapatan harian secara berkala
3. Melihat jam-jam tersibuk transaksi oleh konsumen
4. Mengetahui daftar produk yang paling banyak dibeli
5. Mengevaluasi tingkat keberhasilan status transaksi
6. Membandingkan total pendapatan dari setiap lokasi mesin
